  Headwire (Apple)
</h1>

This repository hosts the macOS app for
[Headwire](https://github.com/brofranks/headwire). See the main repository for
further documentation.

The Headwire CLI is inside the app bundle. You can create an alias:

```sh
alias headwire=/Applications/Headwire.app/Contents/MacOS/Headwire
```

The macOS command line adds a few commands of its own and reads its
configuration from `/etc/headwire`.
